# Contribuindo com o Pagelio

1. Abra uma issue com o comportamento esperado, navegador, versão e passos para reproduzir. Não inclua dados pessoais ou páginas privadas.
2. Faça um fork e uma branch para sua alteração.
3. Execute `npm ci`, `npm run check`, `npm test` e, quando afetar os fluxos, `npm run test:e2e`.
4. Carregue a extensão sem compactação no Chrome e no Edge para validar o clique no ícone, a impressão e os downloads.
5. Abra um pull request explicando a mudança e a validação realizada.

Prefira JavaScript nativo, permissões mínimas e interface em português claro. Não introduza telemetria, código remoto ou dependências de execução sem discussão prévia.
